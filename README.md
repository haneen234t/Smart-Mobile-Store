# 📱 Smart Mobile Store

> **A C++ OOP project for managing a smart mobile store.**

---

## 📝 Project Description
Smart Mobile Store is a simple mobile phone store management system. 
The system allows the Admin to add and manage mobile phones and items easily.

---

## ✨ Project Features
- **Admin and Customer menus**
- **Add new mobile phones**
- **Support Standard and Premium phones**
- **Store phone information** (ID, Name, Price, Quantity)
- **Display all available phones**
- **Search for phones using their ID**
- **Purchase phones and automatically update the quantity**
- **Check product availability before purchasing**

---

## 🛠️ OOP Concepts Used
* **Classes and Objects**
* **Encapsulation**
* **Constructors and Destructors**
* **Inheritance**
* **Polymorphism**
